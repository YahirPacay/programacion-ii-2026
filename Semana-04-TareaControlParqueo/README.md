## Eventos del programa

El programa debe solicitar y Mostras
- Cantidad de Vehiculos
- Cantidad de horas estacionadas
- Si perdio el Ticket
- El tipo de vehiculos
- Se mostrara un comprobante de pago por vehiculos con los detalles de cobros
- Se mostrara un resumen de la jornada con detalles de recaudacion



Depues se calculara


1. Descuento sobre el total si se estaciono mas de 8H
2. El monto total de las horas estacionadas dependiendo del vehiculo
3. Una multa o recargo si se perdio el ticket
4. Cantidad de tipos de vehiculos que ingresaron
5. Cantidad de tickets perdidos
6. Cantidad de recaudacion;
